## 📖 About

StudyMate AI is an AI-powered educational web application that helps students quickly understand their study notes.

Simply paste your notes, click **Analyze Notes**, and the application generates:

- 📖 Summary
- 💡 Easy Explanation
- 🔑 Important Keywords
- ❓ Quiz Questions

The application uses **Google Gemini AI** to produce clear and easy-to-understand learning material.

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/nabilaqayyum/studymate-ai.git
```

Go to the project

```bash
cd studymate-ai
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```

---

## 🔑 Environment Variables

Create a `.env.local` file.

```env
GOOGLE_API_KEY=YOUR_GOOGLE_GEMINI_API_KEY
```

> **Important:** Never upload your API key to GitHub.

---

## 🚀 Deployment

This project is deployed using **Vercel**.

To deploy:

1. Push the project to GitHub
2. Import the repository into Vercel
3. Add the `GOOGLE_API_KEY` environment variable
4. Deploy
